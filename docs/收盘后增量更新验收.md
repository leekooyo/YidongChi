# 收盘后增量更新验收 · 0.3.0

## 已验证行为

- 增量判断：连续交易日追加、同日覆盖不重复、日期缺口及前收变化回补、停牌不造日线、短历史需要上市元数据。
- 迁移：按原始内容的真实日线日期导入，保留腾讯/东方财富来源，旧文件名日期不会充当成交日。
- 编排：每100只批量报价；报价先落盘，断点继续复用；完整结果与更新中的批次分开保存。
- 数据库：Android内置SQLite事务、覆盖写入、重新打开后历史/元数据/待处理报价/上次完整结果可恢复。
- UI：更新/暂停/继续、筛选和加入自选；计算、推演、预警三页独立性回归。

## 使用边界

手机本地、前台手动更新。无服务器、无定时后台任务；首次建库和断更多日可能需要大量历史请求。正常日约56次清单分页＋56次报价＋指数探测，修复额外计数。每次仍计算全清单，避免只更新昨日候选而漏掉新入池股票。

数据源是否已收盘根据指数时间/日期判断；只能看到上个收盘日时明确沿用该日期。前收价不衔接可触发修复，但无法保证仅凭报价发现全部历史复权修订。股票和指数保持来源配对，估算公式未变；官方日历仍为2026年。
