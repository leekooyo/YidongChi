# 计算、推演与预警解耦验收

日期：2026-11-10。版本：0.2.1 / versionCode 4。

用户确认：三页独立选股，预警可切换全部自选。本次不改异动公式、行情源或明日池筛选范围。

## 行为

- 三个StockWorkspace分别保存股票、搜索、最近记录和输入。行情仍按代码共享，避免同股重复请求。
- 旧selected仅用作首次迁移起点，三个页面在初始化时冻结各自的初始值；不能因为某页从未操作，重启后继续跟随计算页。
- 计算页记住当日/次日和指数输入；推演页保存模式、涨跌幅、路径、指数、重置假设与对比选项。
- 预警当前模式跟随自己的选择；全部自选模式按自选列表展示，空列表不借用计算股，缺行情显示该股自己的错误或重试入口。
- 事件状态按代码索引；补录对话框固定目标symbol。明日池跳转只更改计算页。

同一证券的行情、公告和校准重置属于共享事实；三页的选择和场景输入独立。

## 验证证据

常规JVM测试54项通过，另1项全市场网络测试按默认跳过；安卓Android12/API32模拟器13项通过。日志见validation-v021。

新状态测试先因缺少StockWorkspaces失败，再验证迁移冻结、独立保存、搜索晚到、字段按页面/股票保存及警告范围通过。

安卓先复现旧版推演页没有独立选股入口，再验证实际搜索选择：计算改为300750时推演仍为002242、预警仍为300949；推演和预警随后各自改股，不影响计算。推演连续涨停模式跨页保留。

预警测试补录300949事件，核对保存目标为300949且计算仍为002086；切换全部自选后，正常股票和缺失行情样本都按各自代码呈现。明日池跳转只将计算页设为次日、指数不变。

独立只读复核未发现阻断项，指出事件卡片取消请求后状态可能卡在加载中。设备测试稳定复现“已有记录”被遗留为“正在读取”；修复为取消时还原该股原状态，另一股票状态不变，回归通过。
