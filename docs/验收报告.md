# 异动尺 0.1.0 测试版：交付与验收

日期：2026-11-09。原生 Kotlin，Android 8.0/API26 及以上；compile/target35。

## 交付结果

已构建并安装可运行的个人测试 APK。实现自动行情与价格计算、自选分组/置顶/排序/批量刷新、近期记录、未来十交易日情景、同向多次异动计数、应用内预警、规则查询、历史快照、深浅主题、摘要复制及备份恢复。

价格计算使用精确分数保持收益链，直到最终报价取整；展示理论价、实际报价、窗口、有效基期价和指数起止点位。可以查看全部合法窗口，而非只展示最敏感窗口。

规则资产包含 **54 条规则/来源索引、31 份官方原文和公告文件**。条目区分关键条款已核验、文件细节待核验；不把数量当作穷尽全部历史通知的证明。证据详见 [规则覆盖与依据](规则覆盖与依据.md)。

## 独立审阅及修正

进行了一次独立代码审查，限定于业务正确性、功能和运行问题，没有执行通用安全基线或无关扫描。

已修正的重要问题及对应覆盖：

1. IPO 初始五个交易日、当前无限制状态、深市退市整理不再直接放行。引入实际上市日期，未知且历史过短时限制受影响计算；未来仍在豁免期的日期不生成普通价格窗口。`ipoSixthDayDoesNotInheritFirstFiveDaysReturns`、`ipoProjectionKeepsRemainingExemptDaysExcluded`、`delistingStatusCannotEnterPriceDeviationWindows`。
2. 长停股票缺少对应指数时跳过该日复算并显示原因，不再在界面组合时取空集合的最后元素。`missingIndexReplayDayIsSkippedWithoutReplacingItsDate`。
3. 快照保存规则版本、当时重置条件和已知事件 ID；回放使用快照条件。晚于目标日的重置不影响更早日期。`futureResetCannotEraseEarlierAnalysis`、安卓 `laterResetCannotRewriteCapturedSnapshotContext`。
4. 近期十日使用完整基准交易日期筛选，避免用个股十根 K 线跨越长期停牌。`recentSnapshotEventsUseMarketCalendarThroughStockSuspension`。
5. 已确认、带方向且去重的普通异动独立计数：主板4次、科创/创业3次；情景次数仅在假设重置路径内形成非重叠模拟事件。`confirmedDirectionCountDoesNotCountCandidatesOrOverlapDuplicates`。
6. 候选与确认按证券、事件日和种类合并，确认记录优先；自选事件同步刷新，恢复备份同时恢复提醒和字体设置。`confirmedEventReplacesCandidateAcrossProviderIds`、安卓备份恢复测试。

另有真实失败后修正的价格回归：`5.05 → 5.11` 的循环除法曾使 6.06 临界价多进为 6.07；改用精确分数后通过。停牌间隔指数收益、最小报价差、日度公开信息与异常波动区分亦有测试。

## 尚未消除的研究和产品边界

- 免费事件源覆盖不完整；候选记录不自动成为官方公告或重置依据。用户核对原公告后可补充记录与起算条件。
- 历史收益使用行情源前复权序列。尚缺足够独立的除权参考价、历史证券状态和所有停复牌区间资料；这些输出保留“条件估算”。元数据缺失时会影响部分新股计算可用性。
- 科创板累计端点公式仍是一般条款与特别条款的体系解释；普通停牌窗口及跨版本衔接尚未获得完整官方数值回放。四份真实公告核对的是事件/日期等，不冒称完成价格复算。
- 两类 B 股已经通过真实数据至计算链路验证，但没有完成全部特殊状态的官方案例回归。
- 日历仅收录 2026 年；未公布/未收录年份需要更新。退出前台后停止轮询，不提供后台持续推送。
- 同一公告的不同触发种类目前保留为独立条目，尚未合并成一张多标签卡；同向次数不会因此重复计数。

本版适用于个人试用和条件复核，尚不能称为全市场、全部状态的官方监管结果复现器。

## 执行裁定与恢复

- 用户批准 v2 后直接执行计划，不重复请求确认；方案范围由已批准设计约束。
- 在新建独立 `develop` 仓库开发，没有旧项目基线或额外工作树；源码目录保留分阶段 Git 提交。
- 使用已发布的兼容版本及国内构建镜像，解决下载停滞；镜像不可用会影响首次依赖下载。
- 技能 Bash 辅助脚本以 Windows 等价的任务账本、命令及提交记录替代。
- 选择精确分数用于金融报价正确性，增加少量整数运算成本；没有引入通用防御框架。
- 无限制日期分隔价格候选窗口，普通停牌的其他解释仍保留研究缺口；错误解释可能导致与官方结果有差异。
- 正式事件不足、科创解释、除权与历史状态不充分时保留条件估算，不能以测试通过替代官方规则证据。

本地源码为主要恢复入口。备份导入会保存导入前恢复副本；APK 为测试签名，未进行商店发布。
