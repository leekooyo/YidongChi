# 股票异动规则：首轮官方来源核验记录

核验日期：2026-11-09。用途：为拟议的沪深股票异动价格计算安卓应用提供规则研究底稿。本文是有时间边界的首轮核验，不代表已经收齐沪深所有相关规则，也不构成计算引擎的完整验收。

## 1. 当前最重要的修正

**不能把“主板 ST/*ST 涨跌幅5%、三日偏离±12%”作为当前默认规则。**

- 沪市：《交易规则（2026年修订）》3.3.13规定一般股票涨跌幅10%，风险警示章节没有保留5%的例外；5.4.2规定三日累计偏离±20%。2026年7月6日生效，2023版同时废止。官方起草说明明确风险警示股票由5%改为10%。[发布通知及三个附件](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)。
- 沪市的交易公开信息查询页进一步明确：自2026年7月6日起，ST、*ST累计偏离信息并入20%栏目。这是变更已落实于官方披露页面的独立佐证。[上交所交易公开信息查询](https://www.sse.com.cn/disclosure/diclosure/public/inquirydata/index.shtml?secCode=600262)。
- 深市：《交易规则（2026年修订）》3.3.13规定主板10%、创业板20%；5.4.3第一项规定主板三日累计偏离±20%、创业板±30%，没有保留主板风险警示±12%的单列项；10.9规定2026年7月6日施行并废止2023版。[官方PDF，第13、31、40页](https://docs.static.szse.cn/www/lawrules/rule/trade/W020260424690713155663.pdf)。
- 深市2026年6月30日风险警示板业务指南发布通知，要求7月6日起启用新版风险揭示书，并向旧版签署者告知主板风险警示涨跌幅调整，提供了实施衔接证据。[深证会〔2026〕261号](https://www.szse.cn/lawrules/service/member/t20260630_621404.html)。

边界：这里核实的是当前版本，不是旧12%制度的完整历史沿革。历史回测必须另行找到旧版正式条文、生效日及跨2026年7月6日窗口的衔接口径，不能把当前规则回填历史。

## 2. 累计偏离值：明确条文与待核验解释

### 2.1 沪主板、深主板、创业板：区间收益之差有明确条文

沪市5.4.2第一项和深市5.4.3第一项均明确列出累计公式，可记为：

`D = 100 × [(P末 / P初前 - 1) - (I末 / I初前 - 1)]`

期间发生除权除息，应相应调整证券收盘价。这里是证券区间收益减指数区间收益；不是把每日偏离简单相加，也不是把每日“股票涨幅减指数涨幅”再累乘。公式来源分别为[沪市2026规则附件1，5.4.2](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)和[深市2026规则，5.4.3，第31页](https://docs.static.szse.cn/www/lawrules/rule/trade/W020260424690713155663.pdf)。

计算推导：仅当每日证券收益和指数收益使用相同、连续、正确调整的基准，端点比值才可分别用各自每日收益因子的乘积表示；这是数学等价关系，不是新的交易所条文。实际数据舍入、涨跌停比例替代及除权调整仍需制定独立数据口径。

### 2.2 科创板：保留疑点，不直接宣布适用同一累计公式

已明确的条文：沪市6.10规定三日偏离±30%；6.11规定严重异常波动门槛；6.12规定证券涨跌幅减对应基准指数涨跌幅，并指定上证科创板50成份指数；6.1规定本章未规定事项适用一般规则。[沪市2026规则附件1，第六章](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)。

**仍待核验：**6.10、6.12没有重复列出累计公式。通过6.1援引5.4.2的端点公式存在解释依据，但本轮未找到交易所明确针对科创板确认该累计公式的说明、问答或可复算官方案例。因此，这一适用关系只能标为解释推断。不能把“科创板一定按简单相加”或“一定按端点累乘”写成已经核实的事实。应在规则引擎实现前补齐证据。

## 6. 下一轮验收缺口

1. 补齐科创板累计公式的官方直接说明或可复算案例；同时核实10/30日累计公式的适用解释，不把三日公式的文字位置当作全部窗口已获单独确认。
2. 将四份上市规则的披露、核查、停复牌要求与四份实时监控细则分开建表。“异常交易行为”和“异常波动”不能混成同一个价格阈值。
3. 补齐新股、重新上市、风险警示切换、退市整理、除权除息、停复牌、跨规则生效日等边界及历史版本。
4. 取得官方公告样例验证窗口、重置、指数、精度和边界价格。达到公开信息或异常波动门槛不等于必然停牌；停牌结果还须以适用条款和官方公告核实。

## 7. 补充：严重异常后的10个交易日与10/30日累计阈值是两种时间概念

- 沪主板监控细则第二十七至二十九条：严重异常波动按交易规则认定；发生严重异常后10个交易日内，利用资金、持股优势短时间集中申报加剧波动，属于申报速率异常的监管范围；连续竞价一分钟内单向申报金额巨大的行为受到重点监控。[官方细则，第六节](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20250519_10779397.shtml)。本轮所读正式条文使用“金额巨大”，不自行添加固定金额。
- 创业板监控细则（试行）（2023年修订）第二十四至二十六条：同样是严重异常发生后的10个交易日；第二十六条明确连续竞价一分钟单向申报买入或卖出金额超过1000万元受到重点监控。[官方PDF，第7页](https://docs.static.szse.cn/www/lawrules/rule/allrules/bussiness/W020250327502095568538.pdf)。
- 深主板监控细则第二十七至二十九条也明确严重异常发生后10个交易日的申报速率监管；第二十九条使用一分钟单向申报“金额巨大”的表述。科创板2023正式细则的对应条款仍待补齐。本轮不使用旧投教问答替代现行正式细则，亦不将创业板的1000万元金额直接复制到其他板块。[深主板官方PDF，第9页](https://docs.static.szse.cn/www/lawrules/rule/stock/W020230217570611262391.pdf)、[科创板正式细则](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20250519_10779400.shtml)。

产品含义（设计解释）：回看最近10个交易日是否曾触发10日或30日严重异常，是“事件历史查询”；发生事件之后尚处于10日申报监管期间，是“事件后的期间提示”；未来10个交易日是否可能触发，是依赖未来股价和指数假设的“情景推演”。三者须分别命名和计算。前述细则不等于所有股票在该期间禁止交易或必然停牌，也不足以单独证明全部“重点监控名单”的进入和退出规则。起算日、停牌日和重复事件如何延长期间仍需官方公告样例核验。
