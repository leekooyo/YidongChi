# 异动尺 0.3.2 测试版 · 今日池按候选刷新

盘中进入「自选 → 今日池 → 更新盘中数据」，按实时获取的个股和指数报价计算当日严重异动临界价。盘中结果保存在内存里，收盘后仍可从「明日池」增量更新全市场。

今日池每天使用上一交易日收盘批次筛出的候选名单。即使个股暂时跌出结果，后续刷新仍会检查它。池外新出现的候选由收盘扫描发现。缺少当天名单时，页面会提示先在收盘后更新明日池。

74 项常规 JVM 测试和 4 项安卓股票池测试通过。模拟器样本中，300 只股票只有 1 只候选，盘中只请求这 1 只的报价。

安装包为 0.3.2（版本代码 7），支持覆盖同签名旧版。Release 提供 APK、源码 ZIP 和 SHA-256 校验文件。
