# 异动尺 0.2.1 测试版：独立选股与预警

计算、推演和预警各自选择股票，互不替换；预警可切换查看全部自选。

## 更新

- 三页新增各自的选股状态、搜索结果和最近记录，分别保存，重启后恢复。
- 计算的当日/次日及指数输入、推演的模式/涨跌幅/路径/重置假设分别保留；换页或改计算股不再重置推演。
- 预警页支持“当前股票 / 全部自选”，按股票展示数据缺失、事件状态、近期记录和条件复算。
- 补充已确认事件保存到预警页正在编辑的股票，不再误用计算页代码。
- 从自选或明日池打开股票只改变计算页；明日池仍设为次日、指数不变。
- 修复事件请求取消后一直显示“加载中”的状态。

行情缓存、公告和同股的重置校准继续共用，避免重复请求；页面选择和输入分别管理。原异动算法与明日池范围不变。

## 验证

54项常规JVM测试、13项安卓模拟器测试通过。新增用例覆盖三页不同股票、搜索晚到、恢复迁移、推演输入保留、全自选局部缺数据、预警事件归属、明日池跳转边界，以及事件请求取消恢复。

本版没有重复扫描全市场；0.2.0的扫描记录与四只固定截图股票的价格回归保留。完整日志见docs/validation-v021，详情见docs/页面解耦验收.md。

本工具仍为价格条件估算测试版；官方认定、历史状态和日历范围等限制见README。0.2.0 Release及其附件保持不变。
