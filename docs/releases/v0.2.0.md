# 异动尺 0.2.0 测试版：明日异动池

本版新增全沪深A股“明日可能异动股票池”，继续使用原生Android、免费公开行情和本地计算。入口：**自选 → 明日池**。

## 下载

- `YidongChi-0.2.0-debug.apk`：安卓安装包，Android 8.0及以上，个人测试签名。
- `YidongChi-0.2.0-source.zip`：源码、规则归档、构建说明和验收记录。
- `SHA256SUMS.txt`：上述附件的SHA-256校验值。

包名 `cn.yidongchi.app`，版本 `0.2.0` / `versionCode 3`。可覆盖此前同签名的测试版，无需注册。

## 本版新增

- 全沪深A股明日池，默认指数不变，筛选次日涨跌停范围内可能达到10日或30日严重异动价格条件的股票。
- 上行/下行、条件类型、只看自选、按所需幅度排序；显示现价、触发价及所需涨跌幅。
- 一键加入自选，点击股票进入“次日、指数不变”的单股计算页。
- 扫描进度、暂停和继续、失败重试、批次保存与按日缓存；退出前台暂停。
- 主日线源失败时，个股和对应指数成组切换备用源。

## 修正与体验

- 缺少相关历史指数日期时，明确记录为未计算，避免漏掉候选后显示成功。
- 精确批量计算移出安卓主线程；暂停后不再发起备用源请求，并断开正在使用的HTTP连接。
- 限制旧缓存保留范围，保留待恢复批次；精简扫描概况，保持清晰卡片边界。
- 保留0.1.1的连续涨跌停输入修复及今天/次日计算口径。

## 实际验证

- 常规JVM测试50项通过，安卓模拟器测试9项通过。
- 全市场网络测试已手动启用并通过；2026-11-09行情清单5,563条全部处理，其中5,216只完成计算、347条排除、0条读取失败。
- 同次快照得到6只候选（上行5、下行1），不代表当前实时数量。
- 固定截图样本次日价一致：九阳26.88、东方海洋4.64、奥雅64.76、贝特利41.34。

完整日志、排除原因和验证范围见仓库 `docs/明日异动池验收.md` 与 `docs/validation-v020/`。

## 使用时注意

第一次扫描需读取大量日线，保持应用在前台；可暂停后继续。未完成和失败项目不会当作完整结果，排除不等于没有异动。

本版为条件计算测试版，复权收益、特殊状态和公告重置仍有核验边界。触及价格条件不等于交易所已经认定异动。官方日历目前只收录2026年；提醒仅在前台运行。
