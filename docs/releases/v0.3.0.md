# 异动尺 0.3.0 测试版 · 收盘后增量更新

明日池不再每天逐股重新扫描历史。升级后导入旧缓存，收盘后点击“更新收盘数据”，批量读取报价，在手机本地重算全部沪深A股。

- 正常连续交易日只追加一条日线；股票缺口、前收价不衔接或短历史元数据缺失时定向修复。
- 同日重复更新复用完整结果；报价分批保存，暂停后可继续。
- 更新未完成或部分失败时保留上次完整候选，不用半成品替换。
- “更多”提供强制同步本日与重建历史库。
- 计算、推演、预警继续独立选股，异动计算公式沿用此前版本。

无需服务器、注册和额外运行依赖。保持前台，收盘后手动更新；首次无缓存或断更多日仍可能需要较多历史请求。免费行情的日期和可用性以接口实际返回为准，历史复权修订未全面独立核实。
